## 一句话结论

**两个模型跨域变差（BGE nDCG@10 −1.54、Reranker −4.88），一个持平（CLIP），零个变好。**

但三个限制必须先说清，否则结论会被误读：

1. **自有语料基准全部饱和** —— LCQMC base nDCG@10 = 0.9990、MS MARCO base = 1.0000。
   随机负例构不成挑战，**"自有语料上没变差"这句话没有信息量**。
2. **CLIP 的持平是 lr 太小**（1e-7，比另两个低 2-3 个数量级），约等于没训。
3. **跨域变差的归因和直觉相反** —— 见下。

## 最反直觉的发现

诊断显示训练后**逐对 margin 从 0.0934 涨到 0.1440（+54%）、配对准确率 85%→86%**，
但全量 R@1 是跌的。

原因是**相似度绝对尺度塌缩**：正负例相似度从 0.70/0.60 一起掉到 0.55/0.40，
负例掉得更狠，所以 margin 变大。而配对准确率只问"正例比**它自己的**负例高吗"（局部），
R@1 要求**16 候选全局排序**——尺度塌缩在全局排序下伤害更大。

> **教训**：同类实验只报 margin 或配对准确率，会得出**完全相反**的结论。
> 必须报 R@k / nDCG@10 这类全池排序指标。

## 为什么这些结果不能推广到"继续预训练没用"

三次运行的共同特征：单 epoch、沿用验收 lr（未为新目标调小）、跨领域语料、
负例质量低（in-batch 或随机）。**要判断"继续预训练本身"是否有用，
至少需要一次 lr 调小 + 混原任务数据 + hard negative 的对照实验。**
