## 两套折扣系数，以官方为准

| 来源 | 昆仑芯 | 昇腾 | PPU | 训练达标 |
|---|---|---|---|---|
| **官方（2026-11-06 提供）** | **2.182** | **1.410** | **1.031** | **0 / 8** |
| 我们实测（FP16/BF16/带宽，不含 FP32） | 1.321 | 1.050 | 0.711 | 1 / 8（PPU CLIP）|

**判定以官方系数为准（0/8 达标）。** 我们实测那组用于交叉验证与归因——
官方值普遍高于实测（昆仑芯 BF16 +47%、PPU +67%），所以门槛更高、判定更严。
